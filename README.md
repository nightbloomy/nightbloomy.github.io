# NightBloomy Portfolio

A responsive, pastel personal portfolio made with plain HTML, CSS and JavaScript. No framework, build step, paid hosting, or dependencies required.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `nightbloomy.github.io` (for a user site) or `nightbloomy-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait a minute or two. GitHub will show your published website URL in the Pages section.

## Personalize before sharing
- In `index.html`, update the intro, About section, interests, project cards and contact email.
- Replace `hello@example.com` with an email address you are comfortable making public.
- In `style.css`, edit the color variables under `:root` to change the palette.
- Add project links by wrapping project titles or buttons in links.

## Important
Anything you publish on GitHub Pages is public. Don't put your home address, phone number, private school details, passwords, or other sensitive information on the site.
